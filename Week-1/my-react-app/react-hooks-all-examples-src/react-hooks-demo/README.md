# React Hooks Demo

This `src` folder contains simple examples for:

## Built-in hooks

- useState
- useEffect
- useRef
- useMemo
- useCallback
- useContext
- useReducer
- useImperativeHandle
- useLayoutEffect
- useInsertionEffect
- useId
- useTransition
- useDeferredValue
- useSyncExternalStore

## Custom hooks

- useFetch
- useHttp
- useToggle
- useLocalStorage

## Install / run

This assumes an existing Vite React + Tailwind CSS app.

Replace your existing `src` folder with this one, then run:

npm run dev

The `useFetch` and `useHttp` examples use JSONPlaceholder, so internet access is required for those two demos.
