The Complete Hook Cheat Sheet

| Hook                   | Main purpose                       | Nice use case        |
| ---------------------- | ---------------------------------- | -------------------- |
| `useState`             | Manage component state             | Counter / form       |
| `useEffect`            | Perform side effects               | API call             |
| `useRef`               | Keep mutable value / DOM reference | Focus input          |
| `useMemo`              | Cache calculated value             | Filter large list    |
| `useCallback`          | Cache function reference           | Memoized child       |
| `useContext`           | Share data without prop drilling   | Theme / user         |
| `useReducer`           | Manage complex state               | Shopping cart        |
| `useImperativeHandle`  | Expose child methods               | Custom input focus   |

| `useLayoutEffect`      | Work with DOM before paint         | Measure element      |

| `useInsertionEffect`   | Insert styles before layout        | CSS-in-JS            | 
| `useId`                | Generate unique IDs                | Form accessibility   |
| `useTransition`        | Mark update as non-urgent          | Large list filtering |
| `useDeferredValue`     | Defer a value                      | Search results       |
| `useSyncExternalStore` | Connect external store to React    | Online status        |
| `useDebugValue` 		 | Display custom Hook debug information | React DevTools 	 |

What is Hydration?
Hydration is the process where React takes HTML that was already generated on the server and makes it interactive in the browser.
A simple way to remember it:
Server gives you HTML → Browser displays it → React "hydrates" it with JavaScript and behavior.
