We can build it progressively:
1. Axios configuration
2. JOIN API functions
3. Reusable table component
4. JOIN demonstration page
5. Buttons for:
   - INNER JOIN
   - LEFT JOIN
   - RIGHT JOIN
   - FULL OUTER JOIN
   - CROSS JOIN
   - NATURAL JOIN
   - SELF JOIN
   - Employees without Department
   - Departments without Employees
   - Employee + Projects
   - Employee + Department + Projects
6. Display the selected JOIN result in a clean table.
7. Add a small JOIN explanation heading for teaching purposes.
