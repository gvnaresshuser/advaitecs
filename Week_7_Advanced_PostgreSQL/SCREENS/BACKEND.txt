Backend API examples
Once the SQL is understood, students can see how the same queries become APIs.
Employees with departments
GET /api/employees/with-departments

Backend query:
SELECT
    e.employee_id,
    e.employee_name,
    e.salary,
    d.department_name
FROM employees_advaitecs_advpgsql e
INNER JOIN departments_advaitecs_advpgsql d
    ON e.department_id = d.department_id;

All departments with employees
GET /api/departments/with-employees

Using:
LEFT JOIN

Employees and projects
GET /api/projects/employees

Using the three-table JOIN.
Department statistics
GET /api/departments/statistics

Using:
COUNT()
AVG()
GROUP BY
HAVING

Paginated employees
GET /api/employees?page=1&limit=5

Backend:
SELECT *
FROM employees_advaitecs_advpgsql
ORDER BY employee_id
LIMIT $1
OFFSET $2;
