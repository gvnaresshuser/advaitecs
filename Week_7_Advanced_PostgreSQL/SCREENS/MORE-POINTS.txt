2. Understanding LIMIT and OFFSET
LIMIT → How many records should be returned?
LIMIT 3

means:
Return maximum 3 records.

OFFSET → How many records should PostgreSQL skip?
OFFSET 3

means:
Skip the first 3 records.

Therefore:
Page 1 → LIMIT 3 OFFSET 0
Page 2 → LIMIT 3 OFFSET 3
Page 3 → LIMIT 3 OFFSET 6

The general formula is:
OFFSET = (page - 1) × limit

For example:
page = 2
limit = 3

OFFSET = (2 - 1) × 3
       = 3
	   
Why Do We Need Pagination?
Imagine we have:
1,000,000 employees

If we execute:
SELECT * FROM employees_advaitecs_advpgsql;

the database may return a huge amount of data.
Instead, we can request:
Page 1 → 10 records
Page 2 → 10 records
Page 3 → 10 records
...

This is much more practical for applications.
Typical real-world examples:
Amazon       → Products
LinkedIn     → People
Facebook     → Posts
Banking      → Transactions
HR System    → Employees
E-Commerce   → Orders


One Very Important PostgreSQL Concept
For pagination, we should normally use:
ORDER BY employee_id

before:
LIMIT
OFFSET

For example:
SELECT *
FROM employees_advaitecs_advpgsql
ORDER BY employee_id
LIMIT 3
OFFSET 3;

This gives us stable and predictable pagination.
Without ORDER BY, PostgreSQL does not guarantee a particular row order.

Our email column is already:
